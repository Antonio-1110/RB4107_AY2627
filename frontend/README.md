# Monitoring dashboard

Plain HTML, CSS and JavaScript modules, with no build step and no dependencies.
It polls the Django API in [`django/`](../django) for data. It can send two
kinds of commands to the controller through that API: the **Reset shut-off**
button ([remote_reset.md](../docs/remote_reset.md)) and C4002 radar tuning
([c4002_tuning.md](../docs/c4002_tuning.md)). It never trips a shutdown,
silences the buzzer or drives the relay directly. There is no login, so anyone
who can open the page can use both.

| File | Job |
|---|---|
| `index.html`, `css/dashboard.css` | the page and its styling |
| `js/config.js`, `api.js` | API base URL and poll interval; every API call (GETs, and POSTs for reset, settings and C4002 commands) |
| `js/dashboard.js` | state, polling and rendering of the overview and stall pages |
| `js/mode.js`, `countdown.js`, `chart.js`, `heatmap.js` | Monitor/Tuning mode and theme; the Countdown card; temperature chart; heat map |
| `js/safety_logic.js`, `safety_save.js`, `safety_rules_data.js` | Safety tab: flow strip and rule view; each card's Apply; the rules table (generated by `tools/safety_rules.py gen`, never edit) |
| `js/params.js`, `tiers.js`, `cookware.js`, `cooking_temp.js`, `attendance.js`, `presence_filter.js`, `radar_rules.js` | the settings behind the Safety cards |
| `js/tuning.js`, `live_radar.js` | C4002 radar tuning and live view |
| `js/stall_history.js`, `event_text.js`, `logs.js`, `reset.js` | Stall history tab; event wording; Logs tab; **Reset shut-off** |
| `js/dom.js`, `format.js` | small helpers |

## Running it

Start the backend (`python manage.py runserver` in `django/`, see its
README, or `tools/run_dev.sh`) and open http://127.0.0.1:8000/, or
http://192.168.1.50:8000/ from another machine on the network. Django serves
this folder at `/`, so the page and the API share one origin and port. Opening
`index.html` straight from disk does not work, because browsers block
JavaScript modules and API calls from `file://` pages.

For a demo without hardware, run `python manage.py simulate_fleet --direct`
with `RB4107_LOCATION_CATALOG_FILE=locations.demo.json`.

## Where the data comes from

The API fields and how they map from the firmware's MQTT messages are listed in
[`docs/dashboard.md`](../docs/dashboard.md). Format the code with Prettier
(`npx prettier --print-width 100 --write frontend`) before committing.

## Tests

```bash
node --test frontend/tests/
```

Node 22 or newer, no npm packages. `contract.test.mjs` checks that the page,
the scripts and the stylesheet agree (ids, tabs, grid layouts, colour
variables, field heights); `safety_apply.test.mjs` runs the Safety tab's
modules against a small fake page (`fake_dom.mjs`) and checks what each
card's Apply sends. `tools/run_host_tests.sh` runs them too.
