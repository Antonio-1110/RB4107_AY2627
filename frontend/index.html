How the controller decides

    Possible next transitions
      Safety settings: cooking detection, presence and countdown times

      1Cooking

      —

      Detected by the thermal node: cooking starts when the hottest pixel reaches the cooking temperature.

      More settings

      The cookware profile sets how fast a pan loses heat (its cooling time constant, in brackets). While the pan is only cooling, or its temperature is falling, a buzzer warning or shut-off that falls due is held, up to the maximums below.

      2Presence at the stove

      —

      Detected by the presence nodes' radars. A brief detection does not cancel the countdown; only presence for the full return-confirmation time does.

      More settings

      Radar classification rules

      Distinguish a person walking past from a person cooking. Observe: the classification is reported below but not used. Enforce: a person classified as passing does not count as at the stove. The values are provisional and not yet validated on site.

      3Countdown times

      —

      Measured from the start of the unattended countdown. Hotter pans use shorter times (see More settings).

      More settings

      Tier 1 uses the times above. A tier can only shorten them. Set 0 °C to disable a tier; each tier must start at or above the previous tier's temperature.
